# Unified Inbox

A small Windows app for cleaning up several Gmail and Outlook.com inboxes at once.

- **Cleanup with a preview.** It sorts mail that's already in your inboxes into Receipts, Finance, Jobs, News and Promotions using your rules.
  - Nothing moves until you've reviewed it.
  - During review you can read any message, re-sort single messages or a whole sender, and turn a sender into a rule.
- **Undo.** Every move is logged on your PC, and a cleanup can be undone later.
- **Rules that last.** Import your Gmail filters, edit rules, and apply them to Gmail and Outlook as real filters and rules, so new mail keeps sorting itself.
- **Read and sort.** Browse any folder across all mailboxes: move, archive, junk, delete, or "always file this sender".
- **Private.**
  - Runs on your PC only.
  - Sign-ins stay in your user folder.
  - Mail goes straight between your PC and Google/Microsoft.
- **Updates itself** from this repo with one click.

Setup: see [SETUP.md](SETUP.md). Plain HTML, CSS and JavaScript, plus a small Node server (`server.mjs`), with no dependencies.
